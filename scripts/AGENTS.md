# SCRIPTS AGENT STARTUP LAW

1. Read the root `CLAUDE.md` and `AGENTS.md` first.
2. Search `dev_library_scan.py --query <topic>` before writing new scripts.
3. Existing scripts have contracts in `absurd_worker_contracts.py` — respect them.
4. When creating a new script, declare its mutation class in the docstring.
5. When modifying a script, update its receipt path if the output changes.
6. Do NOT modify scripts in `Krampuschewing/` or `Script_Corpses/` — those are archives.
