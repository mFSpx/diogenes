# GOALS AGENT STARTUP LAW

1. Read root `CLAUDE.md` + `AGENTS.md` first.
2. Read `GOALS/CURRENT_HANDOFF.md` at session start.
3. Write handoffs with exact prefix: `"Save This Prompt, Pass on this Handoff:"`
4. Update `CURRENT_HANDOFF.md` + `GOAL_LOG.md` at every goal step.
5. Don't create files outside `GOALS/` for goal-related content.
6. Use `scripts/goal_handoff.py` when available.
