# GOALS — Operator Goal Handoff State

Goal handoff state for persistent work sessions. Always update `CURRENT_HANDOFF.md` and append to `GOAL_LOG.md`.

## Key Rules

- **Use the exact prefix:** `"Save This Prompt, Pass on this Handoff:"`
- **Update `CURRENT_HANDOFF.md`** with `X/N` progress at every goal step.
- **Append to `GOAL_LOG.md`** with the same entry.
- **Keep notes in `GOALS/`.** Do not create folder sprawl.
- **Use `scripts/goal_handoff.py`** and `GOALS/GOAL_HANDOFF_PROMPT.md` when possible.
- **Goal law:** Every submitted goal plan should end with a handoff step.
- **Technical Summary Review and Dev Notes** after each step: brief, conversational, technically precise.
